➢ Administrar: Es un proceso o serie de actividades continúas y relacionadas, esta se

## Página 157


Rol de supervisor de seguridad
PROCESO DE RESOLUCIÓN DE CONFLICTOS
Los conflictos laborales aparecen cuando
dos  posturas  no  pueden  convivir  en  el
mismo espacio o no consiguen un objetivo
simultaneo. Por ende los intereses entran en
conflicto y es necesaria la intervención.
MEDIACIÓN
Cuando un conflicto llega a un punto muerto, se puede solicitar que un
tercero imparcial, el mediador, logra establecer la comunicación para
que ambas partes se expresen y lleguen a un acuerdo entre ellas.
FACILITACIÓN
Se utiliza en conflictos de baja gravedad. Consiste en que una persona
neutral ayuda a las otras a que dialoguen y resuelvan sus diferencias de
forma diplomática, satisfaciendo sus diversas demandas.
ARBITRAJE
Las partes involucradas solicitan la intervención de una o varias personas
neutrales para que hagan sus apreciaciones respecto al conflicto. Luego,
se suelen entregar recomendaciones para evitar el desacuerdo mutuo.
