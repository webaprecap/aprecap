# Submódulo 2.2: Detectores de Metales y Arcos Electrónicos de Control

## 1. Funcionamiento de Detectores de Metales

* **Función Principal:** Generan una barrera electromagnética para detectar el ingreso no autorizado de elementos metálicos (armas u objetos prohibidos) a un área restringida.
* **Alertas de Detección:** Activación de un dispositivo de señal sonora o lumínica que permite al personal de seguridad identificar a las personas que portan el elemento metálico.

---

## 2. Sistemas Automáticos y Paletas Manuales

* **Sistema Rot-Acces:** Exclusa de puertas giratorias automáticas con arco detector de metales integrado. Permite un acceso continuado de hasta 20 personas por minuto en ambos sentidos.
* **Detectores Manuales de Metales:** Dispositivos portátiles utilizados por vigilantes o guardias de seguridad para realizar la inspección corporal no invasiva en puntos de acceso.
